# retail-sales-profit-analysis
End-to-end Power BI project analyzing sales, profitability, customers, and returns

📊 Retail Sales, Profitability & Return Analysis (Power BI)
Business Problem

A retail business wanted to understand overall sales performance, regional and customer profitability, and identify product-level margin erosion caused by discounting and returns.

Objective:
To build an interactive Power BI dashboard that provides executives with actionable insights into sales trends, profit contribution, customer performance, and product-level return impact.

Data Used:
Superstore retail dataset
Orders, Returns, and regional ownership data

Key Work Done:

Cleaned and transformed data using Power Query

Designed a star-schema data model with a dedicated Date table

Built DAX measures for Sales, Profit, Margin %, YoY Growth, and Returns

Created three report pages:

Sales & Profit Overview

Regional & Customer Analysis

Product & Discount & Return Analysis

Implemented page navigation, synced slicers, and reset filters for better UX

Key Insights:

High sales regions do not always generate high profit margins

Furniture category shows consistently lower profitability

Aggressive discounting negatively impacts profit in some sub-categories

Product returns contribute to noticeable revenue loss

A small number of customers generate a large share of profit

Tools & Skills:

Power BI Desktop, Power Query, DAX, Data Modeling, Dashboard Design
